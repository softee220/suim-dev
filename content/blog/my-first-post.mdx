## 왜 블로그를 시작했나

배운 것을 **기록하지 않으면 금방 잊어버린다**는 걸 여러 번 겪었습니다. 그래서 직접 만든 블로그에 글을 쓰기로 했습니다.

## 앞으로 다룰 내용

- Next.js와 React 학습 기록
- 프로젝트를 만들며 마주친 문제와 해결 과정
- 읽은 자료 정리

> 글은 MDX 파일 하나가 곧 글 하나입니다. 커밋하면 자동으로 배포됩니다.

## 코드도 이렇게 나옵니다

export function greet(name: string) {
  return `안녕하세요, ${name}님!`
