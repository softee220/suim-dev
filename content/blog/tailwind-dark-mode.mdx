## 목표

- 저장된 설정이 있으면 그것을, 없으면 시스템 설정을 따른다
- 새로고침해도 **화면이 깜빡이지 않는다**

## 컬러 토큰

색을 컴포넌트마다 `dark:` 로 나누는 대신, CSS 변수로 토큰을 정의하고 `.dark` 클래스에서 값만 바꿉니다.

```css
:root {
  --background: #ffffff;
  --foreground: #171717;
}

.dark {
  --background: #0a0a0a;
  --foreground: #ededed;
}
```

## 깜빡임 방지

서버는 사용자의 테마를 알 수 없어서, `<head>`의 인라인 스크립트가 첫 페인트 전에 클래스를 붙입니다.

```tsx
<script dangerouslySetInnerHTML={{ __html: themeInitScript }} />
```

## 정리

언어를 지정하지 않은 코드 블록도 제대로 보이는지 확인해 봅니다.

```
npm run dev
npm run build
```
