## 전체 흐름

`content/blog/*.mdx` 파일을 읽어서 화면까지 가는 과정은 세 단계입니다.

| 단계   | 역할                    | 사용 도구         |
| ------ | ----------------------- | ----------------- |
| 읽기   | 파일 목록과 내용 로드   | `fs`              |
| 파싱   | frontmatter와 본문 분리 | `gray-matter`     |
| 렌더링 | MDX를 React 요소로 변환 | `next-mdx-remote` |

## 글 목록과 상세 조회

`lib/posts.ts`에 두 가지 함수를 둡니다.

1. `getAllPosts()`: 최신순으로 정렬된 글 목록
2. `getPostBySlug(slug)`: 글 하나의 메타데이터와 본문

```tsx
const post = getPostBySlug(slug)
if (!post) notFound()
```
